## What this prototype adds

- Authenticated `mode: list_children_page_b927` alongside the existing `list_children` mode, without modifying the original resolver source file.
- Continuation via `DriveApp.continueFileIterator()` / `continueFolderIterator()` with a bounded per-request amount of work: **25 folders, 40 audio files, at most 160 inspected files**.
- Integrity-protected, page-number- and folder-bound cursors signed with HMAC-SHA256 using the existing resolver secret **at runtime**. The secret is not included in this ZIP. Cursor expiry and malformed tokens fail closed.
- Explicit end-of-iterator signal, a guard for missing continuation tokens and tests for large directories and non-audio files.
- No audio bytes, KV updates, cloud resources or streaming changes. The tests run in a mocked Apps Script/DriveApp environment only.

## Critical blockers — why this cannot be deployed as a nightly scanner

1. `DriveApp` iterator continuation is **not** a pinned, immutable Google Drive snapshot. A friend uploading/renaming files during traversal could change results. The prototype returns `snapshotPinned:false`, `stableSnapshot:false`, `orderStable:false`, and `productionCompatible:false` on purpose.
2. The existing B9.2.5 scanner contract requires a genuinely verified begin/page/end snapshot, deterministic page ordering and complete metadata. **This prototype intentionally does not satisfy or connect to that contract.** Do not modify the contract merely to accept its self-declared success.
3. The original LAB resolver uses per-request truncation limits; it cannot detect all files in an oversized folder. This B9.2.7 prototype paginates such a folder but has never been tested with a real Google Drive connection.
4. Both `DriveApp` iterator ordering and Google Apps Script execution/quotas must be tested in a separate authorized staging Apps Script (not the live one). A two-pass verification design and safe changed-story staging are still needed to guard against Drive mutation.
5. No live Cloudflare Worker CPU, D1 writes, Queue scheduling or KV publication has been verified. Automatic nightly scanning is **still OFF**.
6. Do not copy any cursor payloads or resolver secrets into public browser requests. This mechanism is server-to-server only; cursor HMAC protects integrity but does not encrypt the cursor's data.
