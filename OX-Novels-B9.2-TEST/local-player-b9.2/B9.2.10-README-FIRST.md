# OX Novels — B9.2.10 (LOCAL TEST ONLY)

**No Google Drive API call. No Apps Script deployment. No Cloudflare setup or Worker deploy. No D1/KV mutation. No catalog publication.**

This patch adds an offline coordinator that brackets the B9.2.8 independent two-pass DriveApp audit with simulated Google Drive API v3 change-feed tokens using the B9.2.9 validated change-feed parser.

## Apply safely

1. Back up `C:\Users\dundi\OX-Novels-B9.2-TEST`.
2. Extract the B9.2.10 ZIP inside `C:\Users\dundi\OX-Novels-B9.2-TEST`, preserving file paths. Only the two new source and test files plus this README and the new BAT file should be added.
3. Run `local-player-b9.2\B9.2.10-VERIFY-LOCAL.bat` (Node.js 22+).
4. Expect **169 tests, 169 passed, 0 failed** when the B9.2.9 test folder was correctly updated. This adds 19 new tests to the previous 150.
5. Do not run CONFIGURE scripts, Google Apps Script deploys, Wrangler, remote migrations or real Drive tests.

## What changed

- Captures test-injected user start change token before any folder reads.
- For simulated *shared-drive member* scope, requires a separate start token and complete change log for that drive **in addition** to the user's log, and captures both before folder scanning.
- Reads two complete resolver traversals, then drains each required change feed.
- Reports a quiet window only if both traversals match and all required simulated feeds are complete and empty.
- Rejects incomplete or corrupt feeds, missing drive scope, missing tokens, and incomplete/modified resolver traversals.
- The all-story summary rejects duplicate, missing or foreign story results.
- Does not reveal raw Drive IDs, user/drive tokens, or audio file names in result summaries.

## Strict limitations

Google documents *user* and *shared drive* change logs as distinct. Empty user log != no shared-drive changes. Also, DriveApp iterators and change tokens do not create an immutable pinned file snapshot. Even a quiet window is `QUIET_WINDOW_OBSERVED_UNPINNED` and **never** sets `canStage`, `canPublish`, `canSkipFullNightlyScan` or deployment approval to true. The current implementation makes no assertions that the actual Apps Script resolver account identity or sharing permissions are known.

The user-specified **nightly scan of all 242 stories** remains mandatory in this experimental architecture. Cloudflare Worker Free CPU, D1 and Queues quotas are not verified by the local tests. No streaming, paid storage or main OX site code changes are included.
